# 📖 الباحث في القرآن الكريم

برنامج متقدم ومجاني (مفتوح المصدر) للبحث في القرآن الكريم وتحليل الكلمات المصاحبة (المتلازمات اللفظية)، مع ميزات إحصائية متقدمة وتصدير النتائج.

💡 **فكرة المشروع:** د. شعيب يحيى (جامعة سعيدة).

---

## ✨ المميزات الأساسية
- **محرك بحث مرن:** يدعم التطابق التام، البحث الجزئي، الجمل المتصلة، ونظام (و/أو) للكلمات المتعددة.
- **أسرار السياق (الكلمات المصاحبة):** أداة متقدمة تحسب أكثر الكلمات وروداً قبل وبعد الكلمة المبحوثة، مع حساب النسبة المئوية للارتباط وعرضها في "سحابة كلمات" لتسهيل دراسة النظم القرآني.
- **التحليل البياني:** رسم بياني لانتشار الكلمة في القرآن الكريم مقسماً (حسب ترتيب المصحف) و (حسب ترتيب النزول).
- **التصدير الاحترافي:** 
  - تصدير النتائج والإحصائيات إلى ملف **Word (docx)** متوافق 100% مع التنسيق العربي.
  - تصدير الجداول الإحصائية بصيغة **Excel (csv)**.
  - تحميل الرسوم البيانية كصور (PNG).
- **العمل دون اتصال (Offline 100%):** يعتمد البرنامج على قاعدة بيانات SQLite مدمجة ومكتبات محلية، ويعمل دون الحاجة للإنترنت.
